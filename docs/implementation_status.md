# smartGPMS 实施状态

更新时间：2026-09-22

## 2026-09-23 最终代码审查

已完成静态检查和高风险路径复审，并修复：

- CPM 同步失败时水位提前前移、导致 ID 被跳过的问题；
- 同一 CPMID 的照片任务完成后无法再次排队的问题；
- DAS 详情页未弹窗时重复触发 `__doPostBack` 的风险；
- 后台线程因一次异常永久停止的问题；
- DAS 照片接口返回登录 HTML 时被误存为图片的问题；
- 状态文字已到 4、但照片尚未出现时阶段仍显示 0 的问题；
- 原图链接和缩略图链接被重复下载的问题；
- 短铅封号无法进入 OCR 候选、铅封置信度显示 0% 的问题；
- 箱号裁剪误包含紧邻箱型代码的问题；
- OCR 重新处理后仍可能读取旧缓存的问题；
- 未勾选保存密码时旧 DPAPI 凭据未清除的问题；
- 打印待确认记录无超时清理、人工确认/重打原因可为空的问题。

最终结果：Ruff 静态检查通过，13 项自动测试通过，Python 编译检查通过，Windows DPAPI、真实照片 RapidOCR、页面 JavaScript/API 冒烟检查通过。版本更新为 `0.2.1`。

## 已实现

- FastAPI 本地服务和网页工作台；
- 多箱号输入、去重、ISO 6346 校验；
- 仿 SSO 风格的用户名/密码/OTP 登录区；
- Windows DPAPI 凭据加密，OTP 永不保存；
- smartGPMS 独立 Edge 用户目录和 10 分钟会话探活；
- SQLite 的 CPM 索引、照片缓存、OCR 缓存、后台任务、打印状态和打印历史；
- 从 `das_photo` 旧库一次性导入 CPMID/箱号元数据，不复制历史照片；
- 增量 CPMID 水位、近期记录回看、状态 4 预处理队列及 1/5/15 分钟重试；
- 四阶段照片按需下载；
- RapidOCR/ONNX CPU、本机 0/90/180/270 度识别、裁剪和 ISO 6346 校验；
- 六行核验表及绿/红/橙三态；
- 首次打印/重打、最后打印时间和不可变证据目录；
- 打印后人工确认：只有确认成功才更新 `print_status=1`；
- 单元测试、Python 编译检查、真实照片 OCR 冒烟测试和两种页面状态截图检查。

## 已通过真实 DAS 验证

- SSO 登录字段和登录按钮；
- 门证页箱号查询框与查询按钮；
- ASP.NET UpdatePanel 查询完成条件；
- 精确箱号所在行的动态 `__doPostBack`；

- 新密码可由 `gerp-import` 临时 OTP 流程成功登录 SSO/DAS。

## 仍需现场验收

- 使用 smartGPMS 登录区输入一次有效 OTP，验证独立浏览器的完整登录链；
- 选择测试门证执行一次打印，确认默认打印机、系统打印对话框及人工确认流程；
- 用当天状态 4 的实际箱号验证照片 URL、铅封裁剪质量和批量六箱耗时；
- 根据现场数据量调整每轮 CPMID 扫描批次和缓存保留期限。

## 启动方式

首次运行 `setup.bat`，以后运行 `run.bat`。访问地址为 `http://127.0.0.1:8765`。
